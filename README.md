# Complexity Classes Demonstration
This project showcases example algorithms for major time‑complexity classes commonly taught in computer science. Each section includes a short explanation and a Python implementation illustrating how the runtime grows with input size.

The goal is to provide clear, simple examples of:

**O(1)** — Constant time

**O(log n)** — Logarithmic time

**O(n)** — Linear time

**O(n log n)** — Linearithmic time

**O(n²)** — Quadratic time

**O(n³)** — Cubic time

**O(2ⁿ)** — Exponential time

These examples are useful for beginners learning Big‑O notation or anyone who wants a quick reference.

## How to Run
Make sure you have Python installed, then run:

```bash
python complexity_classes.py
```

Each section prints its name, explanation, and output directly to the console.

## Included Complexity Examples
### O(1) — Constant Time
A simple print statement demonstrating an operation that always takes the same amount of time.

### O(log n) — Binary Search
A classic binary search implementation that halves the search space at each step.

### O(n) — Linear Time
A single loop that visits each element once.

### O(n log n) — Merge Sort
A full implementation of merge sort, which recursively splits the list and merges sorted halves.

### O(n²) — Quadratic Time
Nested loops that combine every pair of elements.

### O(n³) — Cubic Time
Triple nested loops that combine every triplet of elements.

### O(2ⁿ) — Exponential Time
A recursive Fibonacci function that calls itself twice per input, generating exponential growth.
The program prints the full Fibonacci sequence up to n.
